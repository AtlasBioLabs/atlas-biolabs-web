## 📊 Metadata Standards

### Title Length
- **Target:** 50-60 characters
- **Format:** [Main Topic] for [Audience] | Atlas BioLabs
- **Example:** "Wholesale Peptides, MOQ & Bulk Supply Support | Atlas BioLabs"

### Meta Description Length
- **Target:** 120-160 characters
- **Format:** Brief overview of what page teaches + commercial context
- **Example:** "Atlas BioLabs supports wholesale peptide buyers with MOQ planning, bulk-pack guidance, documentation support, and quote-led recurring supply workflows."

### H1 Heading
- **One H1 per page**
- **Clear, buyer-focused**
- **Example:** "Wholesale Peptides, MOQ & Bulk Supply Support"

### Canonical URL
- **Format:** `https://www.atlasbiolabs.co/[path]`
- **Self-referencing on all pages**
- **No query parameters**

## 🔧 Troubleshooting

### Page Not Showing in Search
1. Check robots.txt (should not be disallowed)
2. Verify canonical URL
3. Submit to Google Search Console
4. Check for noindex meta tag
5. Wait 2-4 weeks for indexing

### Low Traffic to New Pages
1. Check keyword relevance
2. Verify internal linking
3. Check for duplicate content
4. Improve link anchor text
5. Create backlinks if possible

### High Bounce Rate
1. Check page load speed
2. Verify mobile responsiveness
3. Check CTA placement
4. Review content clarity
5. Check for confusing navigation
